# Geist

**Your AI agents, alive on your desktop.**

Geist is a tiny macOS menu bar app that turns activity from Codex, Cursor, Claude Code, and Claude Cowork into animated desktop pets. See when your agents are working, waiting, finished, or need attention without switching windows.

## Download

[**Download the latest stable version of Geist**](https://github.com/heygeist/geist-public/releases/latest/download/Geist.dmg)

Requires **macOS 13 or later** on **Apple silicon**.

## Install

1. Download and open `Geist.dmg`.
2. Drag **Geist** into **Applications**.
3. Open Geist from Applications.
4. Open **Settings… → Integrations** and install the integrations you use.

Stable builds are signed with a Developer ID certificate and notarized by Apple. Geist checks for updates automatically; you can also check manually from the menu.

## Supported agent apps

- Codex
- Cursor
- Claude Code
- Claude Cowork
